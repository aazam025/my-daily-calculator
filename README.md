IMPORTANT:
A PWA cannot normally be installed properly from a local file:// URL.
Upload this folder to any HTTPS web host (for example GitHub Pages / Netlify),
open the HTTPS URL in Chrome, then choose Install app / Add to Home screen.
After first load it can work offline and the running total is stored locally.
